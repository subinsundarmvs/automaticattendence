# Automated Attendance Management System

## Project Overview
The Automated Attendance Management System is a project developed to modernize the attendance tracking process in educational institutions. By leveraging computer vision and IoT, the system replaces traditional, time-consuming manual attendance methods with a secure, reliable, and contact-less solution.

## Key Features
* **Automated Face Recognition**: Uses OpenCV and the Local Binary Pattern Histogram (LBPH) algorithm to detect and recognize student faces [cite: minireport-converted.pdf].
* **IoT Integration**: Utilizes an ESP32-CAM module to capture live video feeds, which are then processed for recognition [cite: minireport-converted.pdf].
* **Data Automation**: Automatically records student attendance with timestamps directly into Excel sheets and SQL databases, minimizing manual data entry errors [cite: minireport-converted.pdf].
* **User-Friendly Interface**: Includes a GUI developed in Python using Tkinter to manage student enrollment, training the recognition model, and generating attendance reports [cite: minireport-converted.pdf].

## Technologies Used
* **Languages**: Python
* **Computer Vision**: OpenCV
* **Hardware**: ESP32-CAM
* **Data Management**: Microsoft Excel (.xlsx), SQL
